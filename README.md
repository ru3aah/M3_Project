# M3_Project 

On-line shop project develped for training purposes.
## Возможности

- **Управление товарами**
  - Листинги товаров с пагинацией и фильтрацией
  - Организация товаров по категориям
  - Детальные страницы товаров с техническими характеристиками
  - Функция поиска товаров
  - Отслеживание доступности товаров

- **Система пользовательских отзывов**
  - Требуется аутентификация для оставления отзывов
  - Система оценок с расчетом средних значений
  - Создание и отображение отзывов
  - Витрина последних отзывов на страницах товаров

- **Корзина покупок**
  - Функциональность корзины на основе сессий
  - Добавление/удаление товаров из корзины
  - Сохранение корзины между сессиями

- **Раздел руководств и рецептов**
  - Страница с руководствами и рецептами
  - Поиск по товарам и руководствам
  - Фильтрация по категориям
  - Функция поиска

- **API**
  - Доступ к данным товаров и отзывов
  - Добавление товаров и отзывов
  - Обновление данных товаров и отзывов
  - Удаление товаров и отзывов

    
## Технологический стек

- **Backend**: Django (Python веб-фреймворк)
- **База данных**: Совместимо с Django ORM (SQLite, PostgreSQL)
- **Frontend**: Django Templates с HTML/CSS
- **Аутентификация**: Встроенная система аутентификации Django

## app products

### Product
- name - название товара
- slug - для SEO-дружественных URL
- category - связь много к одному с категорией товара
- description - описание товара. Первое предложение до точки или первые 30 
  символов описания отображается в качестве краткого описания на странице со 
  списком товаров
- price - цена товара
- currency - валюта цены товара (3 символа ISO 4217)
  **в текущей реализации пересчет цены из разных валют не реализован**
- stock - количество товара в наличии (integer)
- unit_measure - единица измерения и минимальная единица для заказа
- image - изображение товара
- available - доступность товара

### ProductReview (Отзыв о товаре)
- Связь много к одному с товаром
- Связь много к одному с пользователем
- title - заголовок отзыва
- comment - текст отзыва
- rating - оценка отзыва (1-5)
- Интеграция с аутентификацией пользователей

### Category (Категория)
- name - название категории
- slug - для SEO-дружественных URL
- description - описание категории
- parent - связь один ко многим с категорией родительской категории
- Поддержка иерархической организации

### ProductTechSpec (Техническая спецификация товара)
Технические спецификация товара.
- Связь много к одному с товаром
- хранится в виде JSON объекта 
        {"name":"название параметра", "value":"значение параметра"}
- Поддержка многих произвольных спецификаций

## app orders

### Cart
корзина пользователя, реализованная на механизме сессий
- не требуется авторизация для формирования корзины
- актуализация складских запасов на этапе корзины не производится

### Order
заказ сформированный на основе корзины
- для формирования заказа требуется аутентификация пользователя
- заказы автоматически связываются с пользователями и товарами
- после формирования заказа корзина очищается
- в заказе используется снапшот товара - 
  изменение товара после формирования заказа не влияет на снапшот

- user - связь один ко многим с пользователем
- следующие поля модели являются снапшотами и не меняются после формирования 
  заказа 
- ship_full_name - полное имя получателя формируется из полей user
- ship_recipient_phone - телефон получателя
- ship_address_line1 - адрес получателя
- ship_address_line2 - адрес получателя
- ship_city - город получателя

- payment_method - метод оплаты. Выбор из списка:
  - Cash on delivery
  - Credit card
  - Web money

- staus - статус заказа. Выбор из списка:
  - pending
  - paid 
  - Shipped
  - Delivered
  - Canceled

- при изменении статуса получателю направляется e-mail с информацией о заказе

- total_price - сумма заказа
- currency - валюта заказа. В данной реализации только USD и не обрабатывается

### OrderItem
- order - связь один ко многим с заказом
- product - связь один ко многим с товаром
- price - цена товара на момент формирования заказа
- quantity - количество товара в заказе


## Реализации

### ProductListView
- Пагинированные списки товаров (12 товаров на страницу)
- Фильтрация по категориям
- Функциональность поиска
- Опции сортировки (новые, рейтинг и т.д.)
- Краткое описание товара формируется из первого предложения до точки или 
  первых 30 символов если предложение больше 30 символов

### ProductDetailView
- Детальная информация о товаре
- Связанные отзывы (отображаются последние 3)
- Расчет средних оценок на основании отзывов 
- Обработка технических характеристик - показываются в скрываемой зоне 
- Интеграция с корзиной покупок. Изменение кол-ва товара в корзине возможно 
  кнопками + - или прямым вводом кол-ва в поле

### ReviewCreateView
- Требуется аутентификация пользователя
- Создание отзывов о товарах
- Валидация форм и обработка успешного выполнения

### Cart Detail view
- отображение корзины покупок
- добавление товаров в корзину
- удаление товаров из корзины
- обновление количества товаров в корзине

### checkout 
- требует аутентификации пользователя
- формирование заказа на основании корзины происходит после контроля 
  остатков. Если в корзине товара больше, чем на складе, то в заказ попадает 
  число на складе
- во время валидации остатков кол-во товара на складе блокируется. Если 
  товар недоступен к моменту формирования заказа, он удаляется из заказа
- из первого и второго имени пользователя формируется полное имя получателя 
  в заказе
- после успешного формирования заказа корзина очищается

### Order Details
- отображение информации о заказе
- возможность отмены заказа
- возможность оплаты заказа
- возможность получения снапшота заказа

### manage orders
- доступен только администратору
- отображение списка заказов, сортировка по пользователю, статусу, дате
- возможность просмотра деталей заказа и изменения статуса


## Установка


1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/ru3aah/M3_Project.git
   ```

2. **Создание виртуального окружения**
   пример .env в .env.example
Отредактируйте файл .env, задав:
	•	SECRET_KEY — секретный ключ Django
	•	DB_NAME, DB_USER, DB_PASSWORD, DB_HOST — если используете PostgreSQL
	•	DEBUG=1 (для режима разработки)



3. **Сборка и установка зависимостей**
   ```bash
docker compose up --build   
    ```


4. **Выполнение миграций**
   ```bash
docker compose exec web python manage.py migrate   
    ```

6. **Создание суперпользователя**
   ```bash
   docker compose exec web python manage.py createsuperuser
   ```

7. **Запуск проекта**
   ```bash
   docker compose up
   ```
   
8. **Открыть в браузере**
   ```bash
   http://localhost:8000/
   ```
   
9. **Административная панель**
   ```bash
   http://localhost:8000/admin/
   ```

## Использование

### Добавление товаров
1. Откройте Django админ-панель по адресу `/admin/`
2. Перейдите в раздел Products (Товары)
3. Сначала добавьте категории, затем товары
4. При необходимости добавьте технические характеристики

### Управление отзывами
- Пользователи должны быть аутентифицированы для оставления отзывов
- Отзывы автоматически связываются с пользователями и товарами
- Средние оценки рассчитываются автоматически

### Корзина покупок
- Функциональность корзины основана на сессиях
- Товары можно добавлять со страниц детализации товаров
- Корзина сохраняется между пользовательскими сессиями

### Особенности
- при локальном запуске работает с SQLite, при использовании Docker - PostgreSQL
- при локальном запуске использует сервер Django, при использовании Docker - Nginx
