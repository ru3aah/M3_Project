# Django E-commerce Проект

Django-приложение для электронной коммерции с каталогом товаров, пользовательскими отзывами, функциональностью корзины покупок и управлением заказами.

## Возможности

- **Управление товарами**
  - Листинги товаров с пагинацией и фильтрацией
  - Организация товаров по категориям
  - Детальные страницы товаров с техническими характеристиками
  - Функция поиска товаров
  - Отслеживание доступности товаров

- **Система пользовательских отзывов**
  - Требуется аутентификация для оставления отзывов
  - Система оценок с расчетом средних значений
  - Создание и отображение отзывов
  - Витрина последних отзывов на страницах товаров

- **Корзина покупок**
  - Функциональность корзины на основе сессий
  - Добавление/удаление товаров из корзины
  - Сохранение корзины между сессиями

- **Технические характеристики**
  - Гибкое хранение техспецификаций на основе JSON
  - Поддержка различных типов значений спецификаций (строки, списки, объекты)
  - Организованное отображение характеристик товаров

## Технологический стек

- **Backend**: Django (Python веб-фреймворк)
- **База данных**: Совместимо с Django ORM (SQLite, PostgreSQL, MySQL)
- **Frontend**: Django Templates с HTML/CSS
- **Аутентификация**: Встроенная система аутентификации Django

## Модели

### Product (Товар)
- Название, описание, цена, доступность
- Связь с категорией
- Slug для SEO-дружественных URL
- Технические характеристики (JSON поле)

### ProductReview (Отзыв о товаре)
- Пользовательские отзывы с оценками (1-5 звезд)
- Временные метки создания отзывов
- Интеграция с аутентификацией пользователей

### Category (Категория)
- Категоризация товаров
- Поддержка иерархической организации

### ProductTechSpec (Техническая спецификация товара)
- Гибкое хранение технических характеристик
- Определения спецификаций на основе JSON

## Ключевые представления

### ProductListView
- Пагинированные списки товаров (12 товаров на страницу)
- Фильтрация по категориям
- Функциональность поиска
- Опции сортировки (новые, рейтинг и т.д.)
- Грациозная обработка ошибок пагинации

### ProductDetailView
- Детальная информация о товаре
- Связанные отзывы (отображаются последние 3)
- Расчет средних оценок
- Обработка технических характеристик
- Интеграция с корзиной покупок

### ReviewCreateView
- Требуется аутентификация пользователя
- Создание отзывов о товарах
- Валидация форм и обработка успешного выполнения

## Установка

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd django-ecommerce
   ```

2. **Создание виртуального окружения**
   ```bash
   python -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

3. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка конфигурации**
   - Скопируйте `config/settings.py.example` в `config/settings.py`
   - Обновите конфигурацию базы данных
   - Установите SECRET_KEY и другие переменные окружения

5. **Выполнение миграций**
   ```bash
   python manage.py migrate
   ```

6. **Создание суперпользователя**
   ```bash
   python manage.py createsuperuser
   ```

7. **Запуск сервера разработки**
   ```bash
   python manage.py runserver
   ```

## Использование

### Добавление товаров
1. Откройте Django админ-панель по адресу `/admin/`
2. Перейдите в раздел Products (Товары)
3. Сначала добавьте категории, затем товары
4. При необходимости настройте технические характеристики

### Управление отзывами
- Пользователи должны быть аутентифицированы для оставления отзывов
- Отзывы автоматически связываются с пользователями и товарами
- Средние оценки рассчитываются автоматически

### Корзина покупок
- Функциональность корзины основана на сессиях
- Товары можно добавлять со страниц детализации товаров
- Корзина сохраняется между пользовательскими сессиями

## API endpoints

- `/` - Главная страница с листингами товаров
- `/products/<slug>/` - Страница детализации товара
- `/products/<slug>/review/` - Добавление отзыва о товаре
- `/guides-recipes/` - Страница руководств и рецептов
